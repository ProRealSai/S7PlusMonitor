# S7Plus 监视器

S7Plus 监视器是给西门子 **S7-1200 / S7-1500** 用的 Windows 桌面软件。它按 TIA 工程里的**符号名**访问 PLC：把变量目录拉下来、挑一批盯着看、必要时改值，并把这台设备常用的监视表和曲线记在本机。下次打开同一份档案，表还在、趋势还在。

它不是 TIA Portal，也不下载程序、不改硬件组态。定位是调试、试运行和现场维护时的「轻量监视表」：不必为了看几个 BOOL、计数值或 REAL 再开一整套工程软件。较新的加密通讯和没有 TLS 的老固件都能连。关主窗口可以缩到系统托盘，轮询继续跑。

## 典型用法

1. 建一份连接档案，填 IP（端口一般是 102），选好安全方式，点连接。  
2. 软件自动浏览当前 CPU 里的符号。在浏览页过滤、点开属性，把要用的点加进监视表。  
3. 到监视页启动周期读取。BOOL 可以一键反转，其它类型按当前显示格式写入。  
4. 把关心的点送进趋势图：上面看滚动实时曲线，需要时把采样落到本机，事后把时间轴拉回去。  
5. 收工可以断开，也可以缩到托盘让它在后台接着采。

每台 PLC 一份档案。档案之间的监视表、趋势设置和历史采样是分开的，换设备不会把上一台的点混进来。

## 连接

连接页管「连哪台、怎么连」。

每份档案有显示名称、IP 或主机名、端口、超时，以及可选的用户名和密码。密码加密存在当前 Windows 用户下，不进明文库；界面里可以临时显示，核对完再藏回去。可以建很多份档案，并指定启动时默认打开哪一份。删除档案时，会连同这份档案的监视变量和趋势配置一起清掉。

连上之后，通讯参数会锁住，避免轮询中途改错 IP 或端口。浏览页、监视页顶部也能看到当前档案和在线状态，随时断开。

安全方式三种，按现场固件选：

- **TLS**：走加密通道，对应新项目、新 CPU。  
- **Legacy Challenge**：给还不走 TLS 的 1200/1500。  
- **Auto**：先试 TLS，不行再退回 Legacy。回退可以由软件连两次完成，也可以交给驱动在一次连接里试完。

监视周期跟档案一起保存，单位是毫秒。可以设得很短、接近连续读，也可以按几百毫秒或几秒扫一眼。连上后会自动拉一次变量目录，不必再单独点一次浏览。

同一页还能看到本机库文件大概占了多少空间、当前这份档案攒了多少历史采样。只想腾磁盘、不想拆监视表时，可以只清理这份档案的历史采样。

## 浏览

浏览页是当前 CPU 的符号目录：序号、符号名、类型，以及「加入监视」。列表按符号、类型、地址过滤；变量很多时也能跟着滚。点一行，下方展开属性，例如访问序列、优化/非优化地址和位偏移、是否对 HMI 可见可访问、数组元素个数和维度。

需要备份目录、或给别人对照 TIA 里的名字时，可以整表导出 Excel。加监视是按行点的，不用手抄符号名，也不用记绝对地址。

程序下载、符号改名或点被删掉之后，监视表里仍可能留着旧名字，监视页会把对不上的符号标出来，避免默默读空。

## 监视

监视页上半是表，下半是趋势，都可以单独折叠。底栏是状态：忙不忙、轮询周期和耗时、连的是哪台、在不在线。

### 监视表

每行是一个符号：类型、显示格式、当前值，以及写入和趋势入口。显示格式按类型对齐常见的 TIA 监视习惯，例如：

- BOOL：Bool，也可以看成十六进制、十进制、二进制  
- 整数：十进制、带符号十进制、十六进制、二进制  
- 字 / 双字一类：默认十六进制，同样可以换成十进制或二进制  
- 浮点：Float，也可以按整数或十六进制看底层  
- 字符串：按文本显示  

启动监视后按档案里的周期刷新质量和数值。BOOL 提供「写入/反转」：读当前值，写相反值。其它类型在强制栏按当前格式输入再写入 PLC。一行可以送进趋势图，也可以从表里删掉（趋势里对应曲线一并拿掉）。表和趋势都可以在监视中途折叠，把面积让给另一半。

### 趋势

每个连接默认一张趋势图。监视行上「加入趋势」之后，曲线出现在下半张图。点数有上限，避免一次把整台 CPU 都拖进图里把内存撑满。

实时视图按滚动时长画最近一段时间，Y 轴可以自动，也可以手写上下限。历史视图把采样写到本机：自己选采样间隔，时间轴可以是「最近 N 秒/分」，也可以指定起止时刻（结束时间可以一直跟到现在）。实时和历史的坐标轴是分开设的。

图可以暂停。暂停后滚轮缩放、拖拽平移，看完一键重置视野。设置改的是这份档案自己的趋势，不会改到其它 PLC。

## 关窗口和托盘

点关闭时可以选：

- **最小化到托盘**：主窗口隐藏，后台继续连、继续采，托盘提示里能看到是否还在线、是否还在监视。  
- **退出程序**：断开 PLC，结束进程。  
- **取消**：回到窗口。

也可以记住以后默认缩到托盘或直接退出，少弹一次。从托盘可以再把窗口唤回来。

## 数据放在哪

档案、监视表、趋势视图和历史采样都在**当前 Windows 用户**的本地应用数据里，不跟着安装目录走。重装软件一般不会丢配置；换 Windows 用户则看不到另一份数据。密码单独加密存放，不进明文库。
